# 그림 넣는 곳

이 폴더에 그림을 넣으면 앱이 **자동으로** 기본 SVG 그림 대신 그 그림을 보여 줍니다.
파일이 없으면 기본 SVG 그림이 나오므로, 그림이 없어도 앱은 정상 작동합니다.
(외부 인터넷 주소는 전혀 사용하지 않습니다.)

파일 이름에 **한글과 띄어쓰기**를 그대로 써도 됩니다.

---

## 1. 표지와 배경

| 파일 | 쓰이는 곳 | 권장 |
|---|---|---|
| `표지.png` | 첫 화면 표지 | 가로로 긴 그림 (16:10 정도) |
| `벽지.jpg` | 모든 화면의 배경 무늬 | 이어 붙여도 자연스러운 무늬, 아주 연한 색 |

- 표지는 화면 크기에 맞추어 액자 안에 꽉 차게 들어갑니다. 그림 비율은 자동으로 맞춰집니다.
- 벽지는 바둑판처럼 반복되며, 글씨가 잘 보이도록 위에 옅은 미색 막을 한 겹 덮습니다.
- 파일 이름을 바꾸려면 `js/data/activities.js` 의 `App.IMAGE_BASE` 에서 `cover`, `wallpaper` 값을 고치세요.

## 3. 함께하는 사람 — `images/avatars/`

계획·일기에서 "누구와 할까요?" 에 나오는 그림입니다.
사람 그림이라 위아래로 긴 칸에 담기므로, 서 있는 전신 그림이 잘 어울립니다.

| 파일 이름 | 쓰이는 곳 |
|---|---|
| `엄마.png` | 엄마 |
| `아빠.png` | 아빠 |
| `형제자매-남.png` · `형제자매-여.png` | 형제자매 |
| `친구-남.png` · `친구-여.png` | 친구 |
| `선생님-남.png` · `선생님-여.png` | 선생님 |
| `혼자.png` | 혼자 — **아직 없음** (기본 SVG 그림이 나옵니다) |
| `가족.png` | 가족 — **아직 없음** (기본 SVG 그림이 나옵니다) |

- `혼자.png` 와 `가족.png` 를 이 폴더에 넣으면 **자동으로** 바뀝니다. 코드는 고칠 필요 없습니다.
- 남녀 그림이 둘 다 있는 **형제자매 · 친구 · 선생님**은
  **선생님 설정 → 선택지 → 함께하는 사람 그림 고르기** 에서 학생마다 골라 줄 수 있습니다.
  (어느 쪽을 골라도 문장은 똑같이 "친구와 …" 로 만들어집니다)
- 목록을 고치려면 `js/data/options.js` 의 `D.partners` 를 보세요.

## 5. 활동을 새로 추가하려면

`js/data/activities.js` 한 곳만 고치면 계획 · 일기 · 지도 · 포트폴리오에 모두 반영됩니다.

```js
A({ id: 'movie', area: 'outdoor', name: '영화관 가기',
    imageKey: '영화관',              // → images/activities/영화관.png
    icon: 'frame',                   // 그림이 없을 때 쓸 기본 SVG
    speechName: '영화관 가기',        // 음성으로 읽어줄 이름
    planText: '영화관에 갈 거예요',    // 계획 문장
    diaryText: '영화관에 갔어요',      // 일기 문장 (과거형)
    defaultPlace: '영화관',
    defaultSupplies: ['용돈'] })
```

## 6. 그림 스타일 안내

- 파스텔 색, 수채화 동화풍, 따뜻한 느낌
- 윤곽선은 검정 대신 **짙은 갈색** 계열
- 형태와 윤곽은 또렷하게 (흐릿하거나 뭉개진 효과 금지)
- 배경은 밝고 단순하게, 글자는 그림 안에 넣지 않기
