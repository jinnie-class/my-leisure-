# 준비물 그림 — 여기에 넣어 주세요

계획하GO! 의 `필요한 준비물이 있나요?` 에서 나옵니다.
**파일 이름은 화면에 보이는 말 그대로**입니다.

| 파일 이름 | 그림 내용 |
|---|---|
| `가방.png` | 학교 가방 · 손잡이가 보이게 |
| `물통.png` | 뚜껑 있는 물통 |
| `수건.png` | 접힌 수건 |
| `앞치마.png` | 목끈이 보이는 앞치마 |
| `모자.png` | 챙 있는 모자 |
| `용돈.png` | 지폐와 동전 · 지갑 |
| `사진기.png` | 렌즈가 보이는 사진기 |
| `책.png` | 펼친 책 |

활동마다 따라오는 준비물(상자·색종이·풀·슬라임 …)도 이름 그대로 넣으면 나옵니다.
예 : `색종이.png` · `풀.png` · `슬라임.png` · `물티슈.png`

## 규격

- 정사각형, 배경 투명, **긴 변 512px**
- **글자는 넣지 마세요** — 그림 아래에 앱이 이름을 씁니다
- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다. **한 장씩 넣어도** 바로 보입니다
- 그림을 넣은 뒤에는 크기 줄이기를 한 번 돌려 주세요 :
  `powershell -ExecutionPolicy Bypass -File .\shrink-images.ps1`
