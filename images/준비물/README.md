계획하GO! 의 `필요한 준비물이 있나요?` 에서 나옵니다.
**파일 이름은 화면에 보이는 말 그대로**입니다 (예 : `물통.png`).

지금 이 폴더는 비어 있어서 모두 코드로 그린 SVG 가 나오고 있습니다.

### 지금까지 넣은 것

파일이 **있으면** 그림이 나오고, **없으면** 코드로 그린 그림이 대신 나옵니다.
그래서 한 장씩 넣어도 되고, 넣는 순서도 상관없습니다.

지금 들어 있는 것은 `images/준비물/` 폴더를 열어 보면 바로 알 수 있습니다.

⚠ **파일 이름이 `ChatGPT Image …` 처럼 되어 있으면 앱이 못 찾습니다.**
   앱은 **화면에 보이는 말과 똑같은 이름**으로 그림을 찾습니다.
   그림을 받은 뒤에는 반드시 `물통.png` 처럼 이름을 바꿔 주세요.

## 규격

- 정사각형, 배경 투명, **긴 변 512px**
- **글자는 넣지 마세요** — 그림 아래에 앱이 이름을 씁니다
- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다. **한 장씩 넣어도** 바로 보입니다
- 파일 이름은 **띄어쓰기까지 그대로** (`편한 옷.png` 처럼)
- 그림을 넣은 뒤에는 크기 줄이기를 한 번 돌려 주세요 :
  `powershell -ExecutionPolicy Bypass -File .\shrink-images.ps1`
