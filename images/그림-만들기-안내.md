# 그림 만들기 안내 (ChatGPT 로 만들어 넣기)

이 문서 하나만 보고 그림을 만들어 폴더에 넣으면 됩니다.
**파일 이름만 정확히 맞추면 코드는 고치지 않아도 자동으로 바뀝니다.**

---

## 1. 먼저 — 여가 탐험 지도에 필요한 그림은 이미 다 있습니다

지도(`알아보GO!`)에 나오는 그림은 두 가지뿐입니다.

| 지도에 나오는 것 | 파일 | 상태 |
|---|---|---|
| 활동카드 28장 | `images/activities/*.png` | **28개 모두 있음** ✅ |
| 가운데 '나' 캐릭터 1개 | `images/avatars/*.png` | **36개 모두 있음** ✅ |

> 지도의 발자국·하트·별·물음표 표시는 코드로 그린 그림이라 파일이 필요 없습니다.
> 섬 바탕과 점선도 없앴으므로 배경 그림도 필요 없습니다.

**그래서 지도만 놓고 보면 새로 만들 그림이 없습니다.**
아래 16개는 **계획하GO! · 기록하GO! · 함께하는 사람** 에서 쓰이는, 지금 비어 있는 그림입니다.

## 3. 크기와 형식

| 종류 | 크기 | 배경 | 비고 |
|---|---|---|---|
| 활동 그림 (14개) | **512 × 512 px** 정사각형 | **투명(PNG)** | 화면에서 최대 160px 로 보입니다 |
| 함께하는 사람 (2개) | **512 × 800 px** 세로로 김 | **투명(PNG)** | 서 있는 전신. 기존 `엄마.png` 와 같은 비율 |

- 형식은 **PNG**, 배경은 **투명**으로 저장해 주세요. (흰 배경이면 카드 위에 흰 네모가 생깁니다)
- 그림은 **가운데**에 놓고 사방에 약간 여백을 두세요.
- **글자를 그림 안에 넣지 마세요.** 이름은 앱이 따로 크게 적어 줍니다.

## 4. ChatGPT 에 넣을 문장 (그대로 복사해서 쓰세요)

먼저 아래 **공통 스타일**을 한 번 알려 주고, 그다음 각 그림을 하나씩 요청하면 결이 맞습니다.

### 공통 스타일 (맨 처음 한 번)

```
초등 특수학급 학생용 교육 웹앱에 넣을 그림을 만들 거야.
아래 스타일을 계속 지켜 줘.

- 부드러운 수채화 동화풍, 따뜻하고 밝은 느낌
- 파스텔 색을 쓰되 형태와 윤곽은 또렷하게
- 윤곽선은 검정 대신 짙은 갈색 계열
- 흐릿하거나 뭉개진 효과, 그림자, 질감 배경 없음
- 배경은 완전히 투명 (PNG)
- 사물 하나만 화면 가운데에, 사방에 약간 여백
- 그림 안에 글자·숫자·로고를 넣지 말 것
- 크기 512 x 512 px 정사각형
```

### 활동 그림 하나씩

```
위 스타일 그대로, "뚜껑이 열린 작은 보물상자에 조개와 구슬, 돌멩이가 담긴 모습" 을 그려 줘.
512 x 512, 배경 투명 PNG.
```

괄호 안 설명만 바꿔 가며 14번 반복하세요 (2번 표의 "무엇을 그리나" 칸).

### 함께하는 사람 2개

```
위 스타일 그대로, "초등학생 아이 한 명이 혼자 서서 웃고 있는 전신 모습" 을 그려 줘.
정면을 보고 서 있는 자세, 머리부터 발끝까지 다 나오게.
512 x 800 세로 그림, 배경 투명 PNG.
```

```
위 스타일 그대로, "어른 두 명과 아이 한 명이 나란히 서 있는 가족 전신 모습" 을 그려 줘.
정면을 보고 서 있는 자세, 머리부터 발끝까지 다 나오게.
512 x 800 세로 그림, 배경 투명 PNG.
```

## 5. 넣는 곳

```
D:\클로드\나의 여가생활\images\activities\   ← 활동 그림 14개
D:\클로드\나의 여가생활\images\avatars\      ← 혼자.png · 가족.png
```

파일 이름을 표와 **똑같이** 맞춰 저장하면 끝입니다.
`index.html` 을 다시 열면(안 바뀌면 **Ctrl + F5**) 바로 나옵니다.

한 파일 판(`single-file.html`)에도 넣으려면 다시 만들어 주세요:

```bash
powershell -ExecutionPolicy Bypass -File .\build-single-file.ps1
```
