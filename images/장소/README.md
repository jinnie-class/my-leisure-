## 규격

- 정사각형, 배경 투명, 긴 변 512px 안팎 (다른 선택지 그림과 같게)
- 넣지 않으면 코드로 그린 지도 SVG 가 대신 나옵니다. **한 장씩 넣어도** 바로 보입니다
- 파일 이름에 **한글과 띄어쓰기**를 그대로 쓰면 됩니다
