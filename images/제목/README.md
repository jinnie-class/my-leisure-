# 일기 제목 그림 — 여기에 넣어 주세요

여가 일기 마지막쯤 `일기 제목을 골라요` 화면에 나옵니다.

제목 글자는 활동에 따라 달라지지만(`텃밭 가꾸기` · `그림 그리기` …),
그림은 **제목의 꼴**을 나타내므로 파일 이름은 늘 같습니다.

| 파일 이름 | 어떤 칸 | 그림 내용 |
|---|---|---|
| `제목 그대로.png` | `텃밭 가꾸기` | 글자 없는 **이름표(라벨 태그)**. 크림색 종이에 갈색 끈, 가운데에 밑줄 한 줄 |
| `함께한.png` | `가족와 함께한 텃밭 가꾸기` | **두 아이가 손을 맞잡은 모습**. `images/avatars/` 의 아이들과 같은 얼굴 |
| `처음 해 본.png` | `처음 해 본 텃밭 가꾸기` | **알을 깨고 나온 병아리**. 깨진 알껍데기를 머리에 얹고 있으면 더 분명 |
| `직접 쓰기.png` | 맨 아래 쓰는 칸 | **공책 위에 놓인 색연필** |

기분 칸(`뿌듯한 텃밭 가꾸기`)은 그림이 필요 없습니다.
`images/얼굴표정/` 의 얼굴 그림을 그대로 씁니다.

## ⛔ 하트 · 별 모양은 쓰지 마세요

지도에서 **하트 = 좋아해요**, **별 = 도전하고 싶어요** 를 뜻합니다.
제목에도 같은 모양을 쓰면 **한 그림이 서로 다른 뜻으로 두 번** 보입니다.

같은 까닭으로 아래도 피해 주세요.

| 모양 | 이미 쓰는 뜻 |
|---|---|
| ♥ 하트 | 좋아해요 (지도) |
| ★ 별 | 도전하고 싶어요 (지도) · 뿌듯했어요 얼굴 위 |
| 👣 발자국 | 도장 · 해봤어요 |
| ❓ 물음표 | 잘 모르겠어요 |
| ↻ 도는 화살표 | 또 하고 싶어요 |

## 화풍 (다른 그림들과 맞추기)

`images/준비물/가방.png` · `images/얼굴표정/뿌듯했어요.png` 를 옆에 놓고 보면 가장 빠릅니다.

- **외곽선은 진한 갈색**, 검정이 아닙니다. 두껍게 — 교실 뒤에서도 보이게
- 안쪽 무늬도 같은 갈색 선으로, 바깥보다 조금 얇게
- 채색은 **파스텔**, 부드러운 수채·색연필 질감 (살짝 오돌토돌하게)
- 그림자 없이 **평면적**으로, 모서리는 둥글둥글
- 귀엽고 순한 느낌 (가방에 곰돌이가 붙어 있는 정도)

## 규격

- 정사각형, 배경 투명 PNG, 긴 변 **512px**
- **글자는 넣지 마세요** — 그림 아래에 앱이 제목을 씁니다
- 가장자리에 5~8% 여백
- 네 장을 나란히 놓고 **모양만으로 구별**되어야 합니다.
  색만 다르면 색약 학생이 구별할 수 없습니다
- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다 (지금 상태)

## 그림을 넣은 뒤

`index.html` 의 `?v=` 숫자를 올려야 브라우저가 새 그림을 받아 옵니다.
