# 일기 제목 그림 — 여기에 넣어 주세요

여가 일기 마지막쯤 `일기 제목을 골라요` 화면에 나옵니다.

제목 글자는 활동에 따라 달라지지만(`텃밭 가꾸기` · `그림 그리기` …),
그림은 **제목의 꼴**을 나타내므로 파일 이름은 늘 같습니다.

| 파일 이름 | 어떤 칸 | 그림 내용 |
|---|---|---|
| `제목 그대로.png` | `텃밭 가꾸기` | 글자 없는 **이름표(라벨 태그)**. 크림색 종이에 갈색 끈, 가운데에 밑줄 한 줄 |
| `함께한.png` | `가족와 함께한 텃밭 가꾸기` | **두 아이가 손을 맞잡은 모습**. `images/avatars/` 의 아이들과 같은 얼굴 |
| `처음 해 본.png` | `처음 해 본 텃밭 가꾸기` | **알을 깨고 나온 병아리**. 깨진 알껍데기를 머리에 얹고 있으면 더 분명 |
| `직접 쓰기.png` | 맨 아래 쓰는 칸 | **공책 위에 놓인 색연필** |

기분 칸(`뿌듯한 텃밭 가꾸기`)은 그림이 필요 없습니다.
`images/얼굴표정/` 의 얼굴 그림을 그대로 씁니다.

## ⛔ 하트 · 별 모양은 쓰지 마세요

지도에서 **하트 = 좋아해요**, **별 = 도전하고 싶어요** 를 뜻합니다.
제목에도 같은 모양을 쓰면 **한 그림이 서로 다른 뜻으로 두 번** 보입니다.

같은 까닭으로 아래도 피해 주세요.

| 모양 | 이미 쓰는 뜻 |
|---|---|
| ♥ 하트 | 좋아해요 (지도) |
| ★ 별 | 도전하고 싶어요 (지도) · 뿌듯했어요 얼굴 위 |
| 👣 발자국 | 도장 · 해봤어요 |
| ❓ 물음표 | 잘 모르겠어요 |
| ↻ 도는 화살표 | 또 하고 싶어요 |

## 화풍 (다른 그림들과 맞추기)

`images/준비물/가방.png` · `images/얼굴표정/뿌듯했어요.png` 를 옆에 놓고 보면 가장 빠릅니다.

- **외곽선은 진한 갈색**, 검정이 아닙니다. 두껍게 — 교실 뒤에서도 보이게
- 안쪽 무늬도 같은 갈색 선으로, 바깥보다 조금 얇게
- 채색은 **파스텔**, 부드러운 수채·색연필 질감 (살짝 오돌토돌하게)
- 그림자 없이 **평면적**으로, 모서리는 둥글둥글
- 귀엽고 순한 느낌 (가방에 곰돌이가 붙어 있는 정도)

## 규격

- 정사각형, 배경 투명 PNG, 긴 변 **512px**
- **글자는 넣지 마세요** — 그림 아래에 앱이 제목을 씁니다
- 가장자리에 5~8% 여백
- 네 장을 나란히 놓고 **모양만으로 구별**되어야 합니다.
  색만 다르면 색약 학생이 구별할 수 없습니다
- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다 (지금 상태)

## 그림을 넣은 뒤

`index.html` 의 `?v=` 숫자를 올려야 브라우저가 새 그림을 받아 옵니다.

# 챗GPT에 그대로 붙여 넣을 주문서

## 먼저 — 가장 중요한 것

**`images/준비물/가방.png` 를 대화에 올리고 「이 화풍으로」 라고 하세요.**
말로 설명하는 것보다 그림 한 장을 보여 주는 편이 훨씬 잘 맞습니다.

그리고 **네 장을 한꺼번에 시키지 마세요.** 한 장씩 따로 주문해야 화풍이 흔들리지
않습니다. 두 번째부터는 「앞의 그림과 같은 화풍으로」 를 붙입니다.

## 공통 문단 (네 주문 모두 앞에 붙입니다)

```
초등 특수학급 학생용 앱에 넣을 그림입니다. 아래 화풍을 꼭 지켜 주세요.

· 외곽선은 진한 갈색(#6B4A2F 계열), 검정이 아닙니다. 두껍고 굵기가 고른 선
· 안쪽 무늬도 같은 갈색 선으로, 바깥선보다 조금 얇게
· 채색은 파스텔 — 크림, 살구, 연보라, 연노랑, 하늘색
· 부드러운 수채·색연필 질감, 아주 살짝 오돌토돌하게
· 그림자 없이 평면적으로, 모서리는 둥글둥글, 귀엽고 순한 느낌
· 흰색 하이라이트 점을 두세 개만
· 정사각형 1024x1024, 배경은 완전한 순백색 단색
· 그림은 가운데에, 가장자리에 8% 여백
· 글자·숫자·말풍선은 절대 넣지 마세요
· 하트 모양, 별 모양은 절대 쓰지 마세요 (앱에서 다른 뜻으로 이미 씁니다)
```

## ① `제목 그대로.png` — 나무 팻말

```
(위 공통 문단)

그릴 것 : 땅에 꽂힌 나무 팻말 하나.
· 아래는 갈색 나무 말뚝, 위는 크림색 네모 판
· 판 안에는 글자 대신 연회색 밑줄 두 줄만 (제목을 적을 자리라는 뜻)
· 판 둘레에 연보라색 테두리
· 팻말 아래쪽에 아주 작은 초록 풀 두세 포기
정면에서 본 모습, 기울이지 마세요.
```
▸ 뜻 : **꾸밈말 없이 한 일 이름만** 붙이는 제목.
  팻말은 공책·연필과 실루엣이 뚜렷이 달라서 작게 줄여도 구별됩니다.

## ② `함께한.png` — 손을 맞잡은 두 아이

```
(위 공통 문단)

그릴 것 : 두 아이가 나란히 서서 손을 맞잡은 모습. 가슴 위까지만.
· 왼쪽 아이는 연보라색 옷, 오른쪽 아이는 살구색 옷
· 둘 다 살짝 웃는 얼굴, 볼에 분홍 홍조
· 머리 모양을 서로 다르게 (한 명은 짧게, 한 명은 갈래머리)
· 맞잡은 두 손이 그림 한가운데에 또렷이 보이게
```
▸ 뜻 : **누구와 함께**. 맞잡은 손이 한가운데 있어야 '함께' 가 읽힙니다.
▸ `images/avatars/남자아이.png` 도 같이 올리면 얼굴이 더 잘 맞습니다.

## ③ `처음 해 본.png` — 알에서 갓 나온 병아리

```
(위 공통 문단)

그릴 것 : 알껍데기를 깨고 갓 나온 노란 병아리.
· 아래쪽에 금이 간 크림색 알껍데기 아랫부분
· 병아리는 그 안에 앉아 있고, 머리에는 깨진 알껍데기 조각을 모자처럼
· 눈을 동그랗게 뜨고 놀란 듯 기뻐하는 얼굴, 볼에 분홍 홍조
· 작은 주황색 부리와 발
```
▸ 뜻 : **처음 · 첫 번째**. 하트·별·발자국·물음표와 겹치지 않는 몇 안 되는 그림입니다.
▸ 대안 : 땅을 막 뚫고 나온 새싹. 다만 `텃밭 가꾸기` 활동과 헷갈릴 수 있습니다.

## ④ `직접 쓰기.png` — 공책 위의 색연필

```
(위 공통 문단)

그릴 것 : 펼친 공책 위에 색연필 한 자루가 비스듬히 놓인 모습.
· 공책은 크림색, 줄이 연회색으로 세 줄 (글자는 넣지 마세요)
· 색연필은 연보라색 몸통에 살구색 끝, 깎인 나무 부분이 보이게
· 색연필이 공책보다 앞에, 왼쪽 아래에서 오른쪽 위로 비스듬히
· 공책 왼쪽에 갈색 스프링을 그려 넣으면 더 좋습니다
```
▸ 뜻 : **내가 직접 씀**. 색연필이 주인공이라 ①의 팻말과 헷갈리지 않습니다.

   색만 다르면 색약 학생이 구별할 수 없습니다.

같아집니다. 파일을 이 폴더에 넣고 말씀해 주시면 바꿔 드립니다.
