# 일기 낱말 그림 — 여기에 넣어 주세요

여가 일기(2단계)에서 **낱말을 고르는 칸**에 나옵니다.
파일 이름은 **화면에 보이는 말 그대로**입니다.

## 그려야 하는 것 — 네 장뿐입니다

| 파일 이름 | 어떤 칸 | 그림 내용 |
|---|---|---|
| `만든 작품.png` | 가장 기억에 남는 것은? | 아이가 만든 **종이 공작물** — 색종이로 접은 것이 책상 위에 놓인 모습. 옆에 색종이 몇 장과 풀 |
| `맛있게 먹은 것.png` | 가장 기억에 남는 것은? | **접시에 담긴 간식** — 김밥 한 줄이나 샌드위치, 옆에 포크. 김이 살짝 |
| `더 오래.png` | 다음에는 어떻게? | **모래시계** — 아래로 모래가 쌓이고, 둘레에 시간이 흐르는 곡선 화살표 하나 |
| `사진 넣기.png` | 그림일기에 넣을 그림 | **사진기** — 앞에서 본 모습, 렌즈가 크게. 위에 작은 플래시 |
| `내가 그리기.png` | 그림일기에 넣을 그림 | **도화지 위의 크레파스** — 도화지에 색색 낙서가 조금, 크레파스 두세 자루 |

▸ `내가 그리기` 와 `images/제목/직접 쓰기.png` 는 **다른 그림**이어야 합니다.
  하나는 **그림**을 그리는 것, 하나는 **글**을 쓰는 것입니다.
  그래서 이쪽은 도화지·크레파스, 저쪽은 공책·색연필로 갈랐습니다.

## 그리지 않아도 되는 것 — 이미 있는 그림을 그대로 씁니다

뜻이 같은데 그림을 또 그리면 학생이 **둘을 다른 것으로** 봅니다.
코드에 이미 이어 두었으니 아무것도 하지 않으셔도 됩니다.

| 칸 | 쓰는 그림 |
|---|---|
| 기억 `친구와 함께한 것` | `images/제목/함께한.png` |
| 기억 `처음 해 본 것` | `images/제목/처음 해 본.png` |
| 다음에 `또` | `images/또하기/또 하고 싶어요.png` |
| 다음에 `다른 활동을` | `images/또하기/다른 것도 하고 싶어요.png` |
| 다음에 `친구와 함께` | `images/제목/함께한.png` |
| 장소 `직접 쓰기` (계획·일기) | `images/제목/직접 쓰기.png` |

## ⛔ 하트 · 별 모양은 쓰지 마세요

지도에서 **하트 = 좋아해요**, **별 = 도전하고 싶어요** 를 뜻합니다.
`처음 해 본 것` 이 별이었는데, 병아리 그림으로 바꿨습니다.

발자국(도장) · 물음표(잘 모르겠어요) · 도는 화살표(또 하고 싶어요)도 같은 까닭으로 피합니다.

## 화풍 · 규격

`images/제목/README.md` 의 **공통 문단**을 그대로 쓰시면 됩니다.
`images/준비물/가방.png` 를 챗GPT에 올리고 「이 화풍으로」 라고 하는 것이 가장 잘 맞습니다.

- 정사각형, 배경 흰색으로 받아서 **512px 투명 배경**으로 바꿉니다 (넣어 주시면 제가 합니다)
- 진한 갈색 외곽선, 파스텔 채색, 평면적
- **글자는 넣지 마세요** — 그림 아래에 앱이 낱말을 씁니다
- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다 (지금 상태)

## 그림을 넣은 뒤

`index.html` 의 `?v=` 숫자를 올려야 브라우저가 새 그림을 받아 옵니다.
