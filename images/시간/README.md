# 언제 · 시간대 그림 — 여기에 넣어 주세요

`언제 할까요?` 와 `언제쯤 할까요?` 에서 나옵니다.
둘 다 '언제' 를 묻는 그림이라 **한 폴더에 모아** 두었습니다.
**파일 이름은 화면에 보이는 말 그대로**입니다.

---

## 1. 날짜 그림 4장 — **512 × 512 정사각형**

`어제.png` · `오늘.png` · `내일.png` · `날짜 고르기.png`

### 왜 정사각형인가

앱은 이 네 장을 **정사각 칸(96 × 96)** 에 넣고, 비율을 지켜서 줄입니다.
그래서 **세로가 짧은 그림일수록 화면에서 작아 보입니다.**
2026-08-18 에 재어 본 값입니다 :

| 파일 | 원본 | 같은 96칸에서 보이는 크기 |
|---|---|---|
| `오늘.png` | 512 × 512 | **96 × 96** |
| `어제.png` | 512 × 478 | 96 × 90 |
| `내일.png` | 512 × 424 | 96 × 80 |
| `날짜 고르기.png` | 512 × 341 | **96 × 64** ← 가장 작아 보임 |

넷을 나란히 놓으면 `날짜 고르기` 만 눈에 띄게 작습니다.
**네 장 모두 512 × 512 로 그리면** 크기가 저절로 같아집니다.

### 그림 안에서 지킬 것

- 달력이 **네모 칸의 약 85%** 를 채우도록 (둘레 여백을 네 장 모두 같게)
- 달력을 **화살표까지 포함해서** 가운데에 놓기
- 배경 투명 · **그림 안의 글자는 `어제` `오늘` `내일` 만** (앱이 아래에 이름을 또 씁니다)

### 네 장을 한 벌로 보이게 — 지금 어긋난 것

| | 어제 | 오늘 | 내일 | 날짜 고르기 |
|---|---|---|---|---|
| 링 개수 | 3개 | 2개 | 2개 | 5개 |
| 머리띠 색 | 빨강 | 빨강 | **파랑** | 빨강 |
| 놓인 각도 | 비스듬 | 정면 | 비스듬 | 정면 |
| 달력 모양 | 세로형 | 세로형 | 세로형 | **가로형** |

다시 그리실 때 이렇게 맞추시면 한 벌로 보입니다 :

- **링 3개 · 머리띠 빨강 · 정면 · 세로형 탁상 달력** 으로 통일
- **다른 것은 화살표와 달력 속 그림으로만** 구별
  - `어제` : **왼쪽(←) 파란 화살표** · 달력 속에 지난 날짜에 동그라미
  - `오늘` : 화살표 없음 · 해와 구름 (지금 그림 그대로가 기준)
  - `내일` : **오른쪽(→) 주황 화살표** · 해 뜨는 풍경
  - `날짜 고르기` : 화살표 없음 · 날짜 격자 + 연필 든 손
    (지금은 가로형이라 혼자 달라 보입니다. **세로형으로** 바꿔 주세요)

> 글자를 못 읽는 학생은 **화살표 방향**으로 어제·내일을 가립니다.
> 화살표 방향과 색은 꼭 지켜 주세요.

## 2. 시간대 그림 4장 — **512 × 341 (3:2 가로)**

`아침.png` · `낮.png` · `저녁.png` · `정하지 않아요.png`

날짜 그림과 **크기가 다릅니다.** 이 네 장은 아이콘이 아니라 **풍경 장면**이라,
앱이 3:2 짜리 **장면 카드**로 넓고 크게 보여 줍니다 (226 × 150).

| 파일 이름 | 상태 | 그림 내용 |
|---|---|---|
| `아침.png` | ✅ | 해가 **왼쪽 아래**에서 떠오름 |
| `낮.png` | ✅ | 해가 **가운데 위**에 높이 떠 있음 |
| `저녁.png` | ✅ | 해가 **오른쪽**으로 지는 중 |
| `정하지 않아요.png` | ❌ 아직 없음 | 아래를 보세요 |

### `정하지 않아요` 는 이렇게

이 그림만 **시간대가 아닙니다.** '아직 안 정했다' 는 뜻이라
**해를 그리면 안 됩니다** — 해를 그리는 순간 특정 시간대가 되어 버립니다.

> **같은 공원 · 같은 그림체 · 해가 있던 자리에 물음표**

- 세 장과 **똑같은 배경** : 초록 잔디, 구불구불한 흙길, 나무, 꽃,
  벤치와 가로등, 멀리 집들 (낮 · 저녁 그림의 공원 그대로)
- 하늘의 해 자리에 **노란 물음표 `?` 하나.** 해와 같은 노란색 · 같은 수채화 느낌
- 물음표 뒤에 해처럼 **연한 동그라미**를 깔면 더 잘 어울립니다
- 하늘은 아주 옅게 (아침처럼 밝게도, 저녁처럼 주황으로도 하지 마세요)

**시계는 권하지 않습니다.** 나머지 세 장에 시계가 없어 혼자만 달라 보이고,
시계 읽기를 아직 배우지 않은 학생에게는 뜻이 전해지지 않습니다.

## 넣은 뒤에

1. `powershell -ExecutionPolicy Bypass -File .\shrink-images.ps1`
2. `index.html` 의 `?v=` 숫자 올리기 (안 올리면 예전 그림이 계속 나옵니다)

넣지 않으면 코드로 그린 SVG 가 대신 나옵니다. **한 장씩 넣어도** 바로 보입니다.
