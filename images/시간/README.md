# 언제 · 시간대 그림 — 여기에 넣어 주세요

`언제 할까요?` 와 `언제쯤 할까요?` 에서 나옵니다.
둘 다 '언제' 를 묻는 그림이라 **한 폴더에 모아** 두었습니다.
**파일 이름은 화면에 보이는 말 그대로**입니다.

## 날짜

| 파일 이름 | 상태 |
|---|---|
| `오늘.png` | ✅ |
| `어제.png` | ✅ (기록하GO! — 일기는 지난 일을 씁니다) |
| `내일.png` | ✅ (계획하GO! — 계획은 앞일을 세웁니다) |
| `날짜 고르기.png` | ✅ |

## 시간대 — **네 장이 한 벌**입니다

| 파일 이름 | 상태 | 그림 내용 |
|---|---|---|
| `아침.png` | ✅ | 해가 **왼쪽 아래**에서 떠오름 |
| `낮.png` | ✅ | 해가 **가운데 위**에 높이 떠 있음 |
| `저녁.png` | ✅ | 해가 **오른쪽**으로 지는 중 |
| `정하지 않아요.png` | ❌ 아직 없음 | 아래를 보세요 |

### `정하지 않아요` 는 이렇게 그려 주세요

이 그림만 **시간대가 아닙니다.** '아직 안 정했다' 는 뜻이라
**해를 그리면 안 됩니다** — 해를 그리는 순간 특정 시간대가 되어 버립니다.

> **같은 공원 · 같은 그림체 · 해가 있던 자리에 물음표**

- 세 장과 **똑같은 배경**으로 : 초록 잔디, 구불구불한 흙길, 나무, 꽃,
  벤치와 가로등, 멀리 집들 (낮 · 저녁 그림의 공원 그대로)
- **하늘의 해 자리에 노란 물음표 `?` 하나.**
  해와 같은 노란색 · 같은 수채화 느낌으로 둥글둥글하게
- 물음표 뒤에 해처럼 **연한 동그라미**를 깔아 주면 세 장과 더 잘 어울립니다
- 하늘은 아주 옅게 (아침처럼 밝게도, 저녁처럼 주황으로도 하지 마세요)

**왜 시계를 안 그리나** : 나머지 세 장에 시계가 없습니다.
혼자만 시계면 한 벌로 안 보이고, 시계 읽기를 아직 배우지 않은
학생에게는 뜻이 전해지지 않습니다.

## 규격

- **512 × 341px (3:2 가로)** — 시간대 네 장은 이 크기로 맞춰 주세요.
  앱에서 **장면 카드**(3:2)로 크게 보여 줍니다
- 배경 투명 (PNG) · **글자는 넣지 마세요** (그림 아래에 앱이 이름을 씁니다)
- 네 장을 **나란히 놓고 봤을 때 하늘만 보고 구별**되게.
  글자를 못 읽는 학생도 고를 수 있어야 합니다

## 넣은 뒤에

1. `powershell -ExecutionPolicy Bypass -File .\shrink-images.ps1`
2. `index.html` 의 `?v=` 숫자 올리기

넣지 않으면 코드로 그린 SVG 가 대신 나옵니다. **한 장씩 넣어도** 바로 보입니다.
