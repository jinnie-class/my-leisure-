# 언제 · 시간대 그림 — 여기에 넣어 주세요

`언제 할까요?` 와 `언제쯤 할까요?` 에서 나옵니다.
둘 다 '언제' 를 묻는 그림이라 **한 폴더에 모아** 두었습니다.
**파일 이름은 화면에 보이는 말 그대로**입니다.

## 날짜

| 파일 이름 | 상태 | 나오는 곳 |
|---|---|---|
| `오늘.png` | ✅ | 계획하GO! · 기록하GO! |
| `어제.png` | ✅ | 기록하GO! (일기는 지난 일을 씁니다) |
| `내일.png` | ✅ | 계획하GO! (계획은 앞일을 세웁니다) |
| `날짜 고르기.png` | ✅ | 둘 다 |

## 시간대

| 파일 이름 | 상태 | 그림 내용 |
|---|---|---|
| `아침.png` | ✅ | 해가 왼쪽 아래에서 떠오르는 모습 · 밝은 하늘 |
| `낮.png` | ✅ | 해가 머리 위 한가운데 · 파란 하늘 |
| `저녁.png` | ✅ | 해가 오른쪽으로 지는 모습 · 주황 하늘 |
| `정하지 않아요.png` | 없어도 됨 | — |

> `오전 · 오후` 에서 `아침 · 낮 · 저녁` 으로 바꾼 까닭은 `인수인계.md` 에 있습니다.
> 파일 이름이 화면에 보이는 말과 **글자 하나까지 같아야** 그림이 붙습니다.

## 규격

- 정사각형, 배경 투명, 긴 변 512px 안팎
- 세 시간대를 나란히 놓고 봤을 때 **해 위치만 보고 구별**되게 그려 주세요.
  글자를 못 읽는 학생도 고를 수 있어야 합니다

- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다. **한 장씩 넣어도** 넣은 것부터 바로 보입니다.
- 규격은 다른 선택지 그림과 같게 : 정사각형, 배경 투명, 긴 변 512px 안팎
- 세 장을 **나란히 놓고 봤을 때 해 위치로 구별되게** 그려 주세요.
  글자를 못 읽는 학생도 해 위치만 보고 고를 수 있어야 합니다.

> `오전 · 오후` 에서 `아침 · 낮 · 저녁` 으로 바꾼 까닭은 `인수인계.md` 에 적혀 있습니다.
