# 또 하기 그림 — 여기에 넣어 주세요

일기를 저장한 뒤 `다음에 또 하고 싶나요?` 에서 나옵니다.
**파일 이름은 화면에 보이는 말 그대로**입니다.

| 파일 이름 | 그림 내용 제안 |
|---|---|
| `또 하고 싶어요.png` | 하트 · 웃는 얼굴 · 엄지 척 |
| `다음에는 다른 활동을 하고 싶어요.png` | 다른 쪽을 가리키는 화살표 · 여러 갈래 길 |
| `잘 모르겠어요.png` | 물음표 · 고개를 갸웃하는 모습 |

- 넣지 않으면 코드로 그린 SVG(하트·별·물음표)가 대신 나옵니다.
- 규격은 다른 선택지 그림과 같게 : 정사각형, 배경 투명, 긴 변 512px 안팎
- 파일 이름이 길지만 **띄어쓰기까지 그대로** 맞춰 주세요.
