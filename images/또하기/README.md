# 또 하기 그림 — 여기에 넣어 주세요

일기를 저장한 뒤 `다음에 또 하고 싶나요?` 에서 나옵니다.
**파일 이름은 화면에 보이는 말 그대로**입니다.

| 파일 이름 | 상태 | 그림 내용 |
|---|---|---|
| `또 하고 싶어요.png` | ✅ 있음 | — |
| `다른 것도 하고 싶어요.png` | **필요** | 하나였던 길이 **둘로 갈라지는 화살표**. 갈라진 끝에 서로 다른 모양을 얹으면 '다른 것' 이 분명해집니다. 연주황·살구 |
| `잘 모르겠어요.png` | 안 그려도 됨 | `images/아직 잘 모르겠어요.png` 를 그대로 씁니다 |

## ⛔ 하트 · 별 모양은 쓰지 마세요

지도에서 **하트 = 좋아해요**, **별 = 도전하고 싶어요** 를 뜻합니다.
또하기에도 같은 모양을 쓰면 **한 그림이 서로 다른 뜻으로 두 번** 보입니다.

또하기의 뜻은 `같은 것을 반복` 과 `다른 것으로 바꿈` 이라서,
**화살표 방향**으로 나타내는 것이 가장 분명합니다.

## 규격

- 정사각형, 배경 투명, 긴 변 512px 안팎
- **글자는 넣지 마세요** — 그림 아래에 앱이 이름을 씁니다
- 선을 두껍게 (교실 뒤에서도 보이게)
- 두 그림을 나란히 놓고 **모양만으로 구별**되어야 합니다.
  색만 다르면 색약 학생이 구별할 수 없습니다
- 넣지 않으면 코드로 그린 SVG 가 대신 나옵니다
