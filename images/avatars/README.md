|---|---|---|
| **함께하는 사람** 12장 | `엄마.png` `아빠.png` `친구-남.png` … | **512 × 512 정사각** |

## 함께하는 사람 — **512 × 512 정사각형 · 상반신**

`누구와 할까요?` 에서 나옵니다.

### 전신에서 상반신으로 바꾸는 까닭

전신으로 그리면 **얼굴이 화면에서 23px 밖에 안 됩니다.** 누가 누구인지
알아보기 어렵고, 카드 좌우 48px 이 그냥 비어 있었습니다.
2026-08-18 에 1024×768 화면에서 재어 본 값입니다 :

| | 예전 (전신 328×512) | 지금 (상반신 512×512) |
|---|---|---|
| 카드 | 132 × 217 | 132 × 217 (그대로) |
| 그림칸 | 66 × 104 | **104 × 104** |
| 얼굴 높이 | 약 23px | **약 57px** |

### 어떻게 그리나

- **가슴 위(머리 + 어깨)** 까지만. 허리 아래는 그리지 않습니다
- 어깨가 **좌우 끝에 거의 닿게**, 머리 위에는 아주 조금만 여백
- 얼굴이 네모 칸의 **가운데보다 조금 위**에 오도록
- 정면을 보고 **웃는 얼굴**로 (표정이 커야 구별됩니다)
- 배경 투명 · **글자 없음** (그림 아래에 앱이 이름을 씁니다)
- 12장을 나란히 놓았을 때 **머리 크기와 어깨 높이가 비슷하게**.
  한 장만 크거나 작으면 눈에 띕니다

### 파일 이름 (12장)

`혼자 남학생` · `혼자 여학생` · `가족 남자아이` · `가족 여자아이` ·
`엄마` · `아빠` · `형제자매 남` · `형제자매 여` ·
`친구-남` · `친구-여` · `선생님 남` · `선생님 여`

> 이름을 바꾸면 그림이 안 붙습니다. **띄어쓰기와 붙임표(-)까지 그대로** 두세요.

### ⚠ 그림을 다 바꾼 뒤에 CSS 한 줄도 고쳐야 합니다

상반신 12장을 모두 넣은 뒤 `css/app.css` 의 `.pick .thumb.portrait` 에서
`aspect-ratio:.64` 를 **`aspect-ratio:1`** 로 고치세요. 그래야 그림칸이 넓어집니다.

**그림보다 먼저 고치면 안 됩니다.** 전신 그림이 든 채로 1 로 바꾸면
사람 카드 7장이 흰 칸을 15px 넘겨서 글자 아랫부분이 잘립니다 (재어 확인).

### 한 장씩 바꿔도 됩니다

전신 그림이 그대로 있어도 찌그러지지 않습니다 — 세로에 맞춰 가운데에
놓이므로 지금과 똑같이 보입니다. 상반신으로 바꾼 것부터 커집니다.
