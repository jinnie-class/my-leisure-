|---|---|---|

## 함께하는 사람 12장 — **전신 그대로 두세요** (다시 안 그려도 됩니다)

`누구와 할까요?` · 계획하기 · 그림일기에서 나옵니다.

### 왜 전신인가 (2026-08-19 결정)

한때 상반신(512×512)으로 다시 그리려 했습니다. 고르는 카드에서 얼굴이
너무 작았기 때문입니다. 그런데 두 가지가 바뀌면서 **전신이 더 낫게** 되었습니다.

1. **그림일기에서 그림 크기를 조절**할 수 있게 되었습니다.
   `일기 고치기 → 그림 재배열하기` 에서 그림을 눌러 크게·작게 합니다.
   전신이어야 장소 배경 위에 사람이 서 있는 것처럼 보입니다.
2. **고르는 카드에서는 앱이 위쪽만 잘라 보여 줍니다.**
   그림을 다시 그리지 않고도 상반신처럼 커집니다.

### 앱이 알아서 하는 두 가지

| 어디 | 어떻게 | 크기 |
|---|---|---|
| 고르는 카드 (`누구와`) | 네모 칸에 채우고 **위쪽에 맞춰 다리를 자름** | 111 → **174px** |
| 그림일기 · 계획표 | **전신 그대로**, 크기는 학생이 조절 | 0.5 ~ 2배 |

1024×768 에서도 그림칸 104×104, 사람 카드 7장이 1쪽에 들어가고
아래 여유 13px 로 글자가 안 잘립니다 (재어 확인).

### 새로 그리거나 바꿀 때

- 크기는 **아무거나 괜찮습니다.** 세로로 긴 전신(328×512 등)이 기본입니다
- **얼굴이 위쪽 절반 안**에 오게 그리세요. 고르는 카드에서 아래를 자릅니다
- 배경 투명 · **글자 없음** (그림 아래에 앱이 이름을 씁니다)
- 12장을 나란히 놓았을 때 **머리 크기와 눈높이가 비슷하게**

### 파일 이름 (12장)

`혼자 남학생` · `혼자 여학생` · `가족 남자아이` · `가족 여자아이` ·
`엄마` · `아빠` · `형제자매 남` · `형제자매 여` ·
`친구-남` · `친구-여` · `선생님 남` · `선생님 여`

> 이름을 바꾸면 그림이 안 붙습니다. **띄어쓰기와 붙임표(-)까지 그대로** 두세요.
