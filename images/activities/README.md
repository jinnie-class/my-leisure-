# 활동 그림 — 여기에 넣어 주세요

여가 계획하기의 `무엇을 할까요?`, 여가 지도의 활동 카드,
계획표·그림일기의 활동 그림에 모두 쓰입니다.

## 규격

- **정사각형 512 × 512px** (지금 있는 45장이 모두 이 크기입니다)
- **배경 투명** (PNG)
- **글자는 넣지 마세요** — 그림 아래에 앱이 이름을 씁니다
- 파일 이름은 **화면에 보이는 활동 이름 그대로** (`음악 듣기.png` 처럼,
  띄어쓰기까지 똑같이)

### 왜 512px 인가

화면에서 가장 크게 나오는 곳이 계획표 오른쪽 그림(최대 200px)입니다.
512px 이면 2배가 넘는 여유가 있어 어떤 화면에서도 흐려지지 않습니다.

| 어디에 나오나 | 크기 |
|---|---|
| 활동 고르기 (`무엇을 할까요?`) | 96 × 96 |
| 여가 지도 활동 카드 | 56 × 56 |
| 계획표 오른쪽 큰 그림 | 120 ~ 200 |

## 넣은 뒤에

1. 크기 줄이기를 한 번 돌립니다 (512px 보다 크면 줄여 줍니다) :
   `powershell -ExecutionPolicy Bypass -File .\shrink-images.ps1`
2. `index.html` 의 `?v=` 숫자를 올립니다 (안 올리면 예전 그림이 계속 나옵니다)

넣지 않으면 코드로 그린 SVG 가 대신 나옵니다. **한 장씩 넣어도** 바로 보입니다.
