# 나의 여가

> 내가 하고 싶은 여가를 계획하고, 즐기고, 기록하며, 나의 여가생활을 알아보아요.

특수교육대상학생이 자신의 여가생활을 **스스로 계획하고 · 기록하고 · 알아보고 · 모아 전시**하는
마무리 단계 교육용 반응형 웹앱입니다.

- 서버 · 로그인 · 회원가입 · 외부 API 없이 **기기 안에서만** 동작합니다.
- 사진과 기록은 밖으로 전송되지 않습니다.
- 인터넷 연결이 끊겨도 그대로 사용할 수 있습니다.

**학생이 쓴 계획 · 일기 · 사진은 그 기기의 브라우저 안에만 저장됩니다.**
이 저장소에는 프로그램과 그림만 들어 있고, 학생 자료는 들어 있지 않습니다.

| **고쳐서 쓸래요** | `인수인계.md` 를 먼저 읽어 주세요. 규칙과 그렇게 만든 이유가 다 적혀 있습니다 |

## 1. 실행 방법

### 방법 ① 폴더째 사용 (권장)

`index.html` 을 브라우저(크롬·엣지)로 열면 바로 실행됩니다.
`images/` 폴더에 PNG 그림을 넣으면 자동으로 반영됩니다.

### 방법 ② GitHub Pages 주소로 열기 (전자칠판에 가장 편함)

주소만 치면 열립니다. USB로 파일을 옮길 필요가 없습니다.
저장소를 고칠 때마다 주소도 저절로 새것이 됩니다.

### 방법 ③ 파일 하나만 사용 (USB·인터넷 없는 교실)

`single-file.html` 파일 하나만 옮겨도 그대로 실행됩니다.
**표지 · 벽지 · 여가지도 바탕 · 단추 그림은 파일 안에 함께 담겨 있고**,
활동·캐릭터 그림은 기본 SVG 그림으로 나옵니다.

> ⚠️ **이 파일은 저장소에 없습니다.** 1.5MB 라서 고칠 때마다 통째로 쌓이기 때문에
> 일부러 빼 두었습니다(`.gitignore`). 아래 한 줄로 직접 만드세요 — 10초면 됩니다.

```bash
powershell -ExecutionPolicy Bypass -File .\build-single-file.ps1
```

표지는 한 파일 판에 담을 때만 긴 변 1500px 로 줄여 넣습니다(파일 크기 때문). 폴더 판은 원본을 그대로 씁니다.
더 크게/작게 담고 싶으면 `-MaxSide 2000 -Quality 90` 처럼 옵션을 붙이세요.

> **사진 기능 참고** — 브라우저에 따라 `file://` 로 열었을 때 사진 저장이 제한될 수 있습니다.
> 그럴 때는 폴더를 학교 내부 웹서버나 공유 폴더에 올려 `http://` 주소로 열면 모든 기능이 동작합니다.
> 글자 기록(계획·일기·지도)은 두 경우 모두 저장됩니다.

## 2. 화면 구성

모든 화면의 내용은 **가운데 1060px 기둥**에 모입니다.
넓은 전자칠판에서도 좌우로 늘어지지 않아 한눈에 들어옵니다. (`css/app.css` 의 `--page` 로 조절)

화면을 단순하게 지키기 위한 규칙:

- **읽어주기는 화면마다 하나** — 제목(또는 그 화면의 주 질문) 옆에 고정
- **지도의 필터·확대 도구는 `찾아보기` 안에 접어 둠** — 평소에는 지도와 요약 한 줄만
- **기간을 바꾸는 단추는 선생님 설정에만** — 학생 화면에는 지금 보는 기간만 글로 표시
- **전시 고르기는 단추 하나로 켜고 끄기** — 아이콘·글자·배경이 함께 바뀝니다
- **첫 화면 코너 카드는 두 줄** — 안내 문장은 읽어주기로만 들려줍니다

| 화면 | 코너 | 하는 일 |
|---|---|---|
| 표지 | — | 첫 화면. 표지 그림 **안쪽**에 단추가 놓입니다 — 왼쪽 위 학생 이름표, 오른쪽 위 **전체화면 · 선생님 설정**, 가운데 아래 **시작하기** |
| 홈 | — | 큰 코너 카드 4개, 오늘의 여가 계획, 학생 이름·캐릭터 |
| 계획하GO! | 파스텔 하늘색 | 어디 → 무엇 → 누구 → 언제 → (장소 → 준비물) → 확인·저장 |
| 알아보GO! | 파스텔 초록색 | 나의 여가 탐험 지도 · 발자국/하트/별/물음표 상태 고르기 |
| 기록하GO! | 파스텔 보라색 | 여가 일기 1·2·3단계, 저장 후 좋아해요·도전 질문 |
| 모아보GO! | 파스텔 살구색 | 기간별 포트폴리오, 전시 기록 고르기, 전시판형·책자형 인쇄 |
| 선생님 설정 | — | 학생·활동·선택지·수준·기간·기록·백업·초기화 |

**선생님 설정과 전체화면 단추는 표지에만 있습니다.** 학생 화면에는 나오지 않아
학생이 실수로 설정에 들어가지 않습니다. (홈 → `표지로` 로 돌아가면 보입니다)

색상은 **구분을 돕는 장식**일 뿐이며, 기능과 상태는 언제나 아이콘과 글자로도 표시됩니다.

## 3. 하나로 이어진 순환 구조

```
        ┌─────────────── 계획하GO! ───────────────┐
        │  활동·사람·날짜를 골라 계획을 저장       │
        ↓                                         │
   홈 화면 "오늘의 여가 계획"                     │
        │  [활동을 했어요]                        │
        ↓                                         │
      기록하GO!  ← 계획 내용(날짜·활동·사람·장소)이 자동 입력
        │  일기 저장
        ├──→ 해당 활동에 "해봤어요" 발자국 자동 등록
        ├──→ "이 활동을 좋아하나요?"  → 하트
        ├──→ "또 하거나 도전하고 싶나요?" → 별
        │        ↓
        │    알아보GO! (여가 탐험 지도에 함께 표시)
        └──→ 모아보GO! (일기·사진이 포트폴리오에 자동 수집)
                 ↓
             "전시할래요" 를 고른 기록만 전시판형·책자형에 실림
```

- 계획을 세우지 않은 활동도 **홈 → 바로 일기 쓰기**로 기록할 수 있습니다.
- 기분이 좋았다는 이유로 '좋아해요'를 자동 추론하지 않고, **반드시 학생에게 물어본 결과**만 저장합니다.

## 4. 데이터 연결 구조

```
js/data/activities.js   활동 목록 · 그림키 · 계획문장 · 일기문장 · 기본 장소/준비물
js/data/options.js      함께하는 사람 · 기분 · 다시하기 · 준비물 · 캐릭터 · 코너 · 문장 틀
js/data/icons.js        PNG 가 없을 때 쓰는 기본 SVG 그림

js/lib/korean.js        조사(은/는·이/가·을/를·와/과) 처리, 날짜 표현, 문장 조립
js/lib/store.js         학생·계획·일기·지도 상태 저장(localStorage) + 백업/불러오기
js/lib/photos.js        사진 저장(IndexedDB, 실패 시 자동 대체) + 1000px 축소
js/lib/speech.js        브라우저 Speech Synthesis 한국어 읽어주기

js/components/common.js 버튼·읽어주기·활동카드·단계표시·무대(좌우 페이지)·확인창 …
js/screens/*.js         홈 · 계획 · 지도 · 일기 · 포트폴리오 · 교사설정 · 학생선택
js/app.js               화면 이동, 인쇄 자리, 첫 실행
```

저장되는 자료의 모양:

```js
학생   { id, name, avatarId, diaryLevel(1~3), planLevel, hiddenActivityIds[],
        partnerIds[], moodIds[], voice, photo, portfolio{rangeId,start,end}, review{} }
계획   { id, studentId, activityId, cardId, partnerId, date, time, place,
        supplies[], memo, doneDiaryId }
일기   { id, studentId, planId, level, date, activityId, cardId, partnerId, place,
        moodIds[], againId, title, text, frames{}, photoIds[], exhibit }
지도   map[studentId][cardId] = { tried, like, challenge, unsure }
사진   IndexedDB 'naui-yeoga-photos' → { id, studentId, kind, dataUrl }
```

> **하위 활동과 지도의 관계** — `간장계란밥` 처럼 하위 활동을 기록하면
> 발자국·하트·별은 대표 카드(`요리하기`)에 표시됩니다.
> 그래서 지도에는 **한 활동카드가 한 번만** 나타납니다.

## 5. 그림(PNG) 교체 위치

그림은 **한 곳에서만** 관리합니다. 자세한 파일 이름표는 [`images/README.md`](images/README.md) 참고.

| 무엇 | 어디에 넣나 |
|---|---|
| 첫 화면 표지 | `images/표지.png` |
| 배경 벽지 | `images/벽지.jpg` (모든 화면에 바둑판처럼 깔립니다) |
| 활동 그림 | `images/activities/<그림키>.png` (예: `캠핑.png`, `요리하기.png`) |
| 학생 캐릭터 | `images/avatars/<그림키>.png` (예: `곰.png`) |
| 함께하는 사람 | `images/avatars/<그림키>.png` (예: `엄마.png`, `친구-여.png`) |
| 그림키·경로 정의 | `js/data/activities.js` 의 `imageKey`, `App.IMAGE_BASE` |

- 파일 이름에 **한글과 띄어쓰기**를 그대로 써도 됩니다.
- PNG 가 없으면 **기본 SVG 그림**이 자동으로 대신 나오므로, 그림이 하나도 없어도 앱은 정상 작동합니다.
- 활동을 추가하려면 `js/data/activities.js` 에 항목 하나만 더 쓰면 계획·일기·지도·포트폴리오에 모두 반영됩니다.
- 외부 이미지 주소는 사용하지 않습니다.

## 6. 스크롤 없이 쓰기 · 좌우 방향키

전자칠판 · 노트북 · 태블릿(가로/세로) · 아이패드에서 **세로 스크롤이 생기지 않도록** 만들었습니다.

- 화면은 언제나 창 높이에 딱 맞고, 넘치는 내용은 **오른쪽 페이지로 이어집니다.**
- 페이지가 2쪽 이상이면 아래에 `1 / 2 쪽` 표시와 `‹ ›` 단추가 나타납니다.
- **← → 방향키**로 페이지를 넘길 수 있습니다. (태블릿에서는 손가락으로 밀어도 넘어갑니다)
- 여가 탐험 지도는 화면 크기에 맞춰 카드 크기를 스스로 정하고,
  `＋ 크게` 로 확대했을 때 넘치는 부분은 **← → ↑ ↓ 방향키**로 움직입니다.

## 7. 특수교육 접근성

- 한 화면에 주요 질문 하나, 선택지는 4~6개
- 주요 버튼 높이 56px 이상, 화면 크기에 따라 글자 크기 자동 확대
- 그림과 글자를 항상 함께 표시 (그림만 보고 추측하지 않게)
- 선택 상태는 굵은 테두리 + 체크 표시 + 배경색을 **함께** 사용 (색만으로 구분하지 않음)
- 이전 · 다음 · 홈 · 읽어주기 단추 위치 고정
- 드래그를 필수 조작으로 쓰지 않음 / 마우스 · 터치 · 키보드 모두 사용 가능
- 자동 화면 전환 없음, 제한시간 없음
- 저장·삭제 전 확인, 삭제와 초기화는 **확인 창 두 번**
- 번쩍임 없음, `prefers-reduced-motion` 지원, 포커스 표시 지원
- 학생 간 점수 · 경쟁 · 순위 기능 없음

## 8. 처음 실행할 때

`학생 1` 예시 프로필과 예시 기록(일기 3개 · 계획 1개 · 지도 표시 5개)이 들어 있어
바로 기능을 확인할 수 있습니다.

지울 때는 **선생님 설정 → 데이터 → 예시 자료 모두 지우기** (확인 두 번).

선생님 설정은 **표지 오른쪽 위 톱니바퀴**를 누르면 바로 열립니다.
학생 화면(홈·계획·일기·지도·포트폴리오)에는 톱니바퀴가 아예 나오지 않아
학생이 실수로 들어갈 일이 없습니다.

```bash
git add -A
git commit -m "무엇을 고쳤는지 한 줄"
git push
```
